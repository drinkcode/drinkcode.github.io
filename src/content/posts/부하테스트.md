# 부하테스트

## 설치

```bash
brew install jmeter
```

```bash
open /usr/local/bin/jmeter
```

![](/images/Clipboard_2021-09-18-14-14-24.png)

테스트 시 봐야할 것은 Load time으로 22는 22ms를 뜻한다

## 지표의미

![](/images/Clipboard_2021-09-18-14-21-44.png)

Sample: 접속수<br/>
Min: 가장 빠르게 접속한 값<br/>
Max: 가장 느리게 접속한 값<br/>
Average: 평균적으로 접속한 시간<br/>
Throughput: 초당 접속한 횟수(높을수록 좋다, 에러가 발생한 경우는 물론 예외)<br/>
Error: 얼마나 에러가 발생하는지<br/>
Std. Dev.: 표준편차(평균으로 부터 각각 요청하는 시간이 얼마나 떨어져 있는지), 이 값이 0이면 모두 평균과 똑같은 시간을 뜻하고, 이 값이 크다면 들쑥날쑥 하다는 뜻

![](/images/Clipboard_2021-09-18-14-19-36.png)

Data: 실제 접속한 시간<br/>
Average: 평균값의 변화<br/>
Medium: 중앙값<br/>
Deviation: 편차(얼마나 평균으로 부터 떨어져 있는가 혹은 균일한가)<br/>
Throughput: 초당 접속한 횟수(높을수록 좋다, 에러가 발생한 경우는 물론 예외)
