# 한페이지 C언어 자료형 크기 정리

8비트 == 1바이트

char 최소 8비트, 보통 8비트  
short 최소 16비트, 보통 16비트  
int 최소 16비트, 보통 32비트  
long 최소 32비트, 보통 32비트, 64비트는 C89에는 없다  
float char크기이상, 보통 32비트  
double float크기이상, 보통 32비트  
long double double이상의 크기
